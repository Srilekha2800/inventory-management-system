# Inventory Management System

A console-based inventory management backend built with Java and MySQL.

This project is being developed as a practical learning project to understand real-world Java backend development, backend architecture, database integration, business logic, and eventually Spring Boot REST API development.

## Current Status

Phase 1 — Requirements & Project Documentation

## Technology Stack

- Java 21
- Core Java
- MySQL
- JDBC
- Spring Boot — planned future version

## Project Goal

To build an inventory management backend while learning how real-world backend systems are designed, structured, implemented, tested, and eventually exposed through REST APIs.
